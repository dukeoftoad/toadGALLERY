# Room schema snapshots (Phase 4 audit finding K)

This directory holds Room's exported schema snapshots for the media
catalogue database (`MediaCatalogueDatabase`, currently at version 1) ---
one JSON file per database version, committed to source control so every
schema change ships with a reviewable diff. The `1.json` snapshot is
generated by the next build (KSP `room.schemaLocation` arg in
apps/gallery/build.gradle.kts). Migrations must be reviewed against these
snapshots before any schema-changing release.
